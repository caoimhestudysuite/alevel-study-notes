Account & setup

Google Drive connection

Use one dedicated Google account to own the private Drive library. When signed in, it uploads PowerPoints, converts them to Google Slides and saves notes to that account's private Drive app-data folder.

Google credentials are not included. Register the exact website origin in Google Cloud. OAuth access tokens are kept in memory. The website is public, but the Drive files are not.

How access works

Parent: Sign in with the admin Google account. Its Drive ownership permits uploading, deleting and sharing the library.

Student: If the same dedicated Google account is shared on the iPad, it has owner access too. There is no genuinely separate student/admin security boundary. For true read-only access, sign the student in with a different Google account and use “share with student”.

Notes: Saved separately under the signed-in account, and restored when the same account opens the app on another device.

The Google connection needs OAuth consent-screen configuration and the Drive API enabled. See SETUP.md before publishing. Don't treat a website login screen as protection for publicly hosted files.
